# 사진 폴더 사용법

이 폴더에 답사 사진을 넣어 두면 build 단계에서 파일 이름만 보고 스팟에 연결합니다.

## 파일 이름 규칙
장소-무엇-번호.jpg  (예: seolbong-main.jpg, seolbong-parking-lower-1.jpg)
- 대표 사진(접힌 카드용)은 "-main"으로 끝냅니다. 장소마다 1장.
- 나머지는 무엇을 찍었는지 짧게 적고 번호를 붙입니다.
- 영문 이름이 헷갈리면 한글로 적어도 됩니다. 예: 설봉공원-아래쪽주차장-1.jpg

## 무엇 예시
main(대표), parking-upper(위쪽 주차장), parking-lower(아래쪽 주차장), parking-front(정문), parking-back(후문),
playground(놀이터), sculpture(조각공원), lake(호수), museum(박물관), entrance(진입로), food(음식)

## 참고
- 사진은 직접 촬영한 것만 넣습니다.
- 크기는 그대로 넣어도 됩니다. build 때 웹용으로 줄입니다.
- 사진이 없는 장소는 사진 없이 나갑니다. 억지로 채우지 않아도 됩니다.
