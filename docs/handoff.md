## 환경 메모

- Node 24 있음, Python 없음. `gh`는 hayoungmom23-a12 계정으로 로그인됨.
- 브라우저 도구의 화면 캡처가 자주 실패한다. 페이지 글 읽기(get_page_text)와 JS 실행으로 확인하는 편이 안정적이다.
- 로컬 미리보기 서버 설정 `.claude/launch.json`(이름 design-preview, 포트 8765)이 지난 세션의 임시 폴더를 가리키고 있어 **지금은 동작하지 않는다**. TRD 결정대로 구현 때 `tools/serve.mjs`를 프로젝트 안에 만들고 launch.json이 그 파일을 가리키게 고친다. `.claude/`는 git에 올리지 않는다.
- 긴 한글 문서를 셸 heredoc으로 쓰면 깨질 때가 있다. Write 도구로 직접 쓰거나 Node 스크립트로 교체하는 편이 안전하다.
- 학습자는 비개발자다. 어려운 용어에는 한 줄 풀이를 붙이고, 파일 조작은 폴더 위치와 클릭 순서까지 단계별로 안내한다. 글보다 그림으로 비교해 보여주면 이해가 빠르다. 결정을 빨리 하는 편이며 "다 추천으로"라고 답하는 경우가 많다.
